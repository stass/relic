    Runs are limited to 5 seconds and 1,000 result rows. Stop cancels the run; you can edit and run again.

    Embed relic in a JavaScript application

    The playground uses a reusable module with typed results, exact integers and byte strings. Each evaluation runs independently in a worker. See the JavaScript API and build instructions. The native command-line tool and C library use the same engine.

    The playground allows 1 MiB of source, 64 MiB of accounted engine storage, 100,000 tuples and 1 MiB of copied output. The Wasm runtime has a separate 256 MiB memory ceiling; browser overhead is outside that ceiling.

    Learn the syntax in the language tutorial, or work with files using the command-line quickstart.
