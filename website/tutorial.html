Language tutorial

This tutorial covers facts, queries, joins, recursion, negation, arithmetic and aggregates.

Each example below is a complete program. Save one as example.dl and run relic -s example.dl.

Facts Joins Recursion Negation Values Aggregates

1. State facts and ask questions

A fact ends in a period. Lowercase names are symbols; uppercase names are variables. A predicate is identified by its name and number of arguments.

depends(web, api).
depends(api, database).
depends(worker, api).

depends(App, api)?

The answer is web and worker. A query returns the named variables in order of first occurrence. Use _ for a value you do not need; each _ is independent. depends(web, _)? is a yes-or-no question with no output columns.

2. Join relations with rules

:- reads “if”, and commas mean “and”. Repeating a variable joins matching values. A head is derived whenever its body holds.

depends(web, api).
depends(api, database).
depends(worker, api).

two_steps(App, Target) :-
    depends(App, Middle), depends(Middle, Target).

two_steps(App, database)?

Several rules with the same head contribute to the same relation. Relations are sets: stating or deriving the same fact twice adds no duplicate.

3. Follow an arbitrary number of steps

A base rule includes direct dependencies. A recursive rule extends an existing chain by one edge. Evaluation stops when no new facts can be derived.

depends(web, api).
depends(api, database).
depends(worker, api).

affected(App, Changed) :- depends(App, Changed).
affected(App, Changed) :-
    depends(App, Middle), affected(Middle, Changed).

affected(App, database)?

Cycles do not keep this program running forever: there are only finitely many pairs of these symbols. Recursion that generates new integers can still grow without bound; use limits for workloads you do not control, for example -l tuples=100000 -l memory=67108864. The memory limit bounds accounted engine storage, not total process memory.

4. Ask what is absent

not tests for absence. First establish the possible values with a positive relation; then exclude the values you do not want.

depends(web, api).
depends(api, database).
depends(worker, api).

service(S) :- depends(S, _).
service(S) :- depends(_, S).
leaf(S) :- service(S), not depends(S, _).

leaf(S)?

database has no outgoing dependency. A variable in a negated literal must already be bound by the rule's positive facts or assignments. Negation is stratified: a relation cannot depend on itself through negation. relic rejects such a program.

5. Compute with values

Values are symbols, double-quoted byte strings, or signed 64-bit integers. The symbol api and the string "api" are different values. Arithmetic belongs in body comparisons; = can bind a computed value.

size(api, 12).
size(web, 7).

larger(Service, Bytes) :- size(Service, N), Bytes = N * 1024,
    Bytes > 10000.

larger(Service, Bytes)?

Operators include +, -, *, / and mod. Overflow and division by zero fail evaluation. String functions include length, cat, substr, index, match and str.

6. Count a group

An aggregate folds the distinct rows inside its braces. A variable shared with the outer rule selects the group; bind it both outside and inside the braces.

depends(web, api).
depends(api, database).
depends(worker, api).

service(S) :- depends(S, _).
service(S) :- depends(_, S).
dependency_count(S, N) :- service(S),
    N = count { depends(S, Target) }.

dependency_count(S, N)?

The result includes database 0: an empty group has a count of zero. sum(Value), min(Value) and max(Value) select the value to fold. Aggregates read complete relations and cannot recurse through themselves.

Keep the variables you want to count: count { depends(S, _) } counts distinct rows with no local columns, so it returns at most one. Using Target preserves each different dependency.
