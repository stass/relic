A small program

What depends on the database?

Two rules follow the whole dependency chain, however many steps it takes.

depends(web, api).
depends(api, database).
depends(worker, api).

affected(App, Changed) :- depends(App, Changed).
affected(App, Changed) :-
    depends(App, Middle), affected(Middle, Changed).

affected(App, database)?

$ relic -s impact.dl
api
web
worker

:- means “if”. Uppercase names are variables. A query ends in ?. These rules also handle cycles.

At home in a pipeline

Import CSV or TSV. Print text, CSV, TSV or JSON. Run a file, ask a query from the command line, or explore in the REPL.

The same engine in C

Load rules, add facts, and stream or collect answers through librelic. No server or language runtime to bring along.

Built for recursive questions

Indexed joins, semi-naive evaluation and query-directed planning keep work focused. Large evaluation rounds can use multiple cores.
